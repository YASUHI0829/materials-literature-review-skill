# Search Taxonomy

Use short query blocks. Mix one term from each group rather than writing one huge natural-language query.

## Material and Product

- target alloy name
- target product form
- target crystal structure
- target sheet material
- close alloy family
- benchmark material from prior studies

## Microstructure and Texture Input

- microscopy map
- orientation map
- grain orientation
- ODF
- pole figure
- inverse pole figure
- crystallographic texture
- texture component
- microtexture
- representative volume element

## Experimental Targets

- uniaxial tension
- compression test
- direction dependent test
- rolling direction transverse direction diagonal direction
- Lankford coefficient
- r-value
- normal anisotropy
- planar anisotropy
- stress-strain curve
- yield stress
- work hardening
- formability

## Physics Model

- crystal plasticity
- CPFEM
- CPFE
- CP-FFT
- simulation code name
- physics-based hardening model
- rate dependent viscoplasticity
- VPSC
- Taylor model
- virtual material testing
- numerical material test

## Calibration and Optimization

- parameter identification
- inverse identification
- Bayesian optimization
- Bayesian calibration
- Gaussian process
- surrogate assisted calibration
- uncertainty quantification
- sensitivity analysis

## Machine Learning

- microstructure property prediction
- texture property prediction
- image to property
- CNN
- graph neural network
- transformer
- neural operator
- physics informed machine learning
- surrogate model
- reduced order model
- active learning
- multi task learning
